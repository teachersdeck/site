What it is

A version of TeachersDeck built to run inside ClassIn's shared Browser tool.

Opens in ClassIn's browser

No extension and no install. Paste a link into ClassIn's Browser tool and the widgets open straight away, on Windows or Mac.

One link, one widget

A link can open a single widget filling the window, already set up: a 5-minute timer, a scoreboard with your team names, or today's agenda.

Students hear the timer

When time is up, a chime plays and the whole window flashes "Time's up! · Hết giờ!", so remote students notice even without sound.

Safe on a shared screen

Every student sees your browser, so widgets with student names, points or progress are switched off in this edition.

Widgets you can open with a link

Seven widgets take ready-made settings in the link, and the full deck is there for everything else.

  • Timer
  • Stopwatch
  • Traffic Light
  • Noise Meter
  • Scoreboard
  • Instructions
  • Agenda

Link builder

Pick a widget, set it up, and copy the link or a QR code. Links work in English and Vietnamese.

Lesson packs

Ready-made sets of links for a whole lesson, from warm-up to exit, so a class runs from one list.

Tested inside ClassIn

Checked in ClassIn's own browser in October 2026: all 8 checks passed, including sound, the microphone and settings that stay saved.

TeachersDeck for ClassIn questions

Which ClassIn plans can use it?

Any ClassIn account that shows the Browser tool in a lesson. If you can open a web page inside a lesson, TeachersDeck works there.

Do my students need to do anything?

No. They see your ClassIn board as usual. Turn on ClassIn's "Share audio" so they hear the timer chime.

Can I use the Noise Meter in ClassIn?

Yes. It works alongside ClassIn's own use of your microphone; this was checked in a real ClassIn lesson.

Is it the same as the TeachersDeck Chrome extension?

It is the same widgets, set up for a shared screen. Already have TeachersDeck Pro? Ask us about adding ClassIn.
