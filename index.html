Four apps, one suite

Each app is for one role, with a familiar look and one shared system behind them.

TeachersDeck

For teachers

A wall of 43 draggable classroom widgets — timers, traffic light, name picker, group maker, attendance, polls, exit tickets, lesson planner — that runs in your browser or as your Chrome new tab.

  • Class Builder: set up classes with Vietnamese and English names
  • Cloud Class: go live so students and parents connect with a code
  • Notes home and progress reports for parents

StudentDeck

For students

A study dashboard for the Chrome new tab: focus timer, homework list, reading log, games, flashcards, dictionary and translate — and, with a class code, points, rewards and badges from the teacher’s class.

A read-only dashboard, updated in real time from the teacher and the child’s app: reward points, behaviour log, class ranking, notes from the teacher, and reading and homework trends.

How they work together

All four share one system, so a point awarded in TeachersDeck shows up in StudentDeck and ParentDeck as soon as it syncs.

  1. Teacher

    Creates a class and shares a student code and a parent code. Sets homework, awards points, adds rewards, sends notes home.

  2. Student

    Joins with the class code and a PIN, ticks off homework, practises, earns and redeems points.

  3. Parent

    Links with the parent code and sees points, homework, reading and teacher notes in real time.

  4. School

    Leaders see every class: activity, homework completion, join codes, rosters and people.

Frequently asked questions

Is TeachersDeck Suite free?

A free plan covers the everyday classroom tools. Pro unlocks the full widget set with a licence key, and Enterprise solutions are available for schools.

Do students need an email address or account?

No. Students join a class with a class code and a PIN, with no email address and no personal account.

Where is classroom data stored?

A teacher’s classroom data is stored on their own device. Cloud features are optional, and a student’s journal never leaves their device.

Which languages does it support?

TeachersDeck, ParentDeck and AdminDeck work in English and Tiếng Việt, and TeachersDeck also has partial Spanish, French, Chinese, Japanese, Korean and Tagalog. StudentDeck is in English, with a built-in translator. It is made for Vietnamese classrooms, with names in Vietnamese order and lunar-calendar dates.

Do I need to install anything?

No install wizard. Open TeachersDeck in a browser, or load it as your Chrome new tab.
