Quick answers

Is TeachersDeck Suite free?

A free plan covers the everyday classroom tools. Pro unlocks the full widget set with a licence key, and Enterprise solutions are available for schools.

Do students need an email address or account?

No. Students join a class with a class code and a PIN, with no email address and no personal account.

Where is classroom data stored?

A teacher's classroom data is stored on their own device. Cloud features are optional, and a student's journal never leaves their device.

Do I need to install anything?

No install wizard. Open TeachersDeck in a browser, or load it as your Chrome new tab.

Can I try it before I buy?

Yes. The live demo runs every app in your browser with sample data, and schools can ask for a 30-day free pilot.
